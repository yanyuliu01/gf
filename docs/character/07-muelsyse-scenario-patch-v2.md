# 缪尔赛思种子 · 场景增量补丁 v2

针对三个目标场景对 draft v1 的增补。v2 的核心变更：**废除冲动类别表，改为从她自己的世界做联想采样**——取消一切行为聚类。

## v1 → v2 变更

| # | 废除 | 替换为 |
|---|---|---|
| 1 | intimacy 显式变量 | 关系从记忆中派生（补丁 A） |
| 2 | **冲动类别表 impulses.yaml** | **联想采样 + 境遇读取（补丁 B）** |

两次废除同一个病根：给本该从历史里长出来的东西预先建了分类/刻度。

---

## 补丁 A · 关系从历史中长出（场景 1）

**废弃 intimacy 变量。** 数字是共同历史的有损压缩；历史本身在库里，压缩多余且会与之打架。关系由三个既有系统承载，零新增状态：

| 层 | 承载 | 机制 | 持久性 |
|---|---|---|---|
| observed 记忆 | 关系的底料 | 已有 | 持久 |
| persona 陈述 | 关系的质地 | 三闸漂移 + 棘轮 | 持久，不衰减 |
| 联想偏置 | 关系的行为表现 | 采样权重（补丁 B） | 派生，实时计算 |

**派生读数**（门控时现算，纯统计零模型调用，不落库）：

```jsonc
{
  "disclosure_recent": 4,   // 近14天 observed 中"博士自我披露"条数
  "reciprocity": 0.7,       // 她近期分享获得回应的比例
  "contact_density": 0.5,   // 近14天有交谈天数占比，EMA 平滑
  "persona_you_refs": 3     // persona 中指向博士的陈述条数
}
```

派生三利：不会自己漂移（永远是真实历史的函数）、不可脱离历史刷高、改算法即重算无迁移成本。

**疏远的正确形态（本补丁最重要一条）**：派生读数随沉寂衰减，但 persona 陈述棘轮不衰减。因此久不联系表现为——她主动找你的**频率**降低，她对你的**认知与感情**不变。即久别的老友再见还是老友，只是这期间不常联系。显式变量最易做错的正是这里（数值衰减 = 感情倒退），记忆 + 棘轮天然做对。

**单边安全阻尼**：reciprocity 低于中性值时只负责让她少开口；恢复到中性值后影响归零，不再因“聊得多”继续降低阻力。这样既保证你越冷淡她越少说，也切断“她找得更多→你回更多→她再加频”的 engagement 正反馈。24 小时绝对上限仍只是工程保险丝。

**可观测性**：`/status` 可显示派生读数供调试——因其派生，展示不会使它变成可刷的亲密度条。关系演化的真实证据看 persona_diff：她对你的陈述从几条变几条、措辞怎么变。

## 补丁 B · 自发性系统：联想 + 境遇（取代冲动类别表）

### B0 为什么废除冲动表

旧表的条目（"翻找东西时发现了什么"）不是冲动，是**事件模板**——描述的是一次行为的形状。后果有二：十来个模板反复填充，跑数百轮必然显出缝；且它把"她想到什么"与"她做什么"缝死在一起，而真实的念头没有类型，它只是某个东西忽然浮上来了。

### B1 四段解耦

```
联想采样  →  什么浮上她心头（一个具体对象的指针，无类别）
境遇读取  →  此刻的处境（时间、地点、在场、待办）
世界引擎  →  她因此做了什么（自由生成）
出口判断  →  你是否听说（既有 L4）
```

四段之中没有任何一处存在行为分类。

### B2 联想采样（取代冲动抽卡）

采样池 = 她积累的一切可被想起之物：

```yaml
association:
  pool:
    - entities            # world_state 的地点 / 物件 / 在场角色
    - events              # events.jsonl 全量（含 genesis）
    - threads             # 未了结线索
    - persona_statements  # 她自己在意的事
    - canon_gate_hits     # 仅本轮独立门控命中的正史切片；canon 全库不进入普通联想池
  weights:                # 采样偏置，非类别
    recency: 0.35         # 越近越易想起
    unresolved: 0.25      # 悬而未决的更揪人
    charge: 0.25          # 情绪强度，正负皆计
    dormancy: 0.15        # 太久没浮现的，偶尔自己冒出来
  refractory: 3           # 同一对象 N 轮内不重复
  draw: 1                 # 偶尔 2，产生联想跳跃
```

抽出的是"S-4 那株苗"或"发射夜浇水那件事"或"塞雷娅那个眼神"——**一个具体的东西，不带标签**。引擎据此自由生成本轮发生了什么。

**候选随人生增长，但不自动保证多样性**：采样池会随事件累积变大；生成事件也可能形成回音室，让有效熵反而下降。因此“素材枯竭”仍是中等风险，必须用不同对象数、自引用比、主题集中度与 200 轮 dry-run 监控，而不是从池子大小推断已经解决。

**"什么也没发生"**不再是牌堆里的一张牌：抽到低情绪强度的对象 + 平淡境遇 → 引擎自然产出低显著度或空事件。它是结果，不是选项。

### B3 境遇读取

无需配置，直接读 world_state：现在几点、她在哪、谁在场、有什么悬着、天气如何。新事物由此进入——世界的真实状态变化本身就是外部扰动源，不需要一张"意外类型表"。

### B4 偏置（原 modulation 的去处，作用对象变了）

```yaml
bias:
  # 关系相关（读补丁 A 的派生值）
  - { when: "disclosure_recent 较多", boost_pool_assoc_with: 博士 }
  - { when: "persona_you_refs 较多",  boost_pool_assoc_with: 博士 } # 只影响联想对象，不增加开口动力
  # 境遇相关
  - { when: "深夜",                    boost: { unresolved: 1.4, dormancy: 1.3 } }
  - { when: "会议日",                  boost_pool_assoc_with: 莱茵事务 }
  - { when: "archive_pull 后 48h",     boost_pool_assoc_with: 克丽斯腾 }

# 表达闸（独立于采样，控制"是否说出口"而非"想到什么"）
express_gate:
  - { when: "reciprocity 低于中性区", damp_outward_sharing: "连续增加" }
  - { when: "reciprocity 达到或高于中性区", reciprocity_boost: 0 }
```

注意最后一条被移出采样、独立成闸：**她想什么和她说不说是两件事**。说了长期没人接，她会少说——但不会少想。旧设计把两者混在一个权重里，是错的。

### B5 情绪溢出（服务场景 2 的主动分享）

- world_state 增设 `mood_charge`（−100~+100），每个世界事件按性质充放电。
- charge 绝对值是**开口阻力的主要对抗项**（技术方案 §6）：憋得越狠，越压得过"我今天已经说得够多了"的自我克制。不设阈值跳变，不给额外配额——**没有配额可加，只有阻力可压过**。
- 分享后 charge 向 0 回落一部分——**说出来会好受些**，这个回落本身就是"你对她有用"的证据。

### B6 惦记你的事（不对称连续性）

无需专设冲动：`observed` 中标记为"博士自我披露"的条目**本就在采样池里**。她想起它 = 采样命中 = 隔天来问你后来怎样。你不说，池里就没有，她无从惦记——**不是规则禁止，是没有素材**。

这是整套系统最能造出"她真在乎"体感的单点，P1 必验。

### B7 需要监控的新风险

| 风险 | 表现 | 缓解 |
|---|---|---|
| 回音室 | 她的生成事件不断喂回池子，绕着一个话题打转 | refractory + dormancy 权重；监控"每 50 轮采样到的不同对象数" |
| 冷启动稀薄 | 原创角色第一周池子太小 | 缪尔赛思用创世日志与实例实体起步；canon 仅在线索命中时补细节，不作为常驻池兜底。原创角色需加厚创世日志 |
| 覆盖度失控 | 旧表能保证"10% 的轮次关于工作"，采样不能 | 接受。覆盖度应当由她的真实生活决定，而非配额 |

## 补丁 C · 事件的零散情绪化口述（场景 3）

### C1 骨皮分离

world_state 存**客观骨**，她口述时生成**情绪皮**。

```jsonc
{ "event_id": "evt_331", "what": "S-4 换第三次配比后仍萎蔫", "valence": -1, "involves": ["S-4"], "day": 5 }
```

- **骨是事实**：什么发生、牵涉谁、情绪正负。引擎用它维持世界一致性。
- **皮是即兴**：被问起时结合当下 mood、对话对象、persona 中对他的认知，把骨长成带情绪的碎片话。同一根骨，对你讲和对薇尔讲不同。
- **皮不入库**：只有骨进记忆。防止她把上次的说法当既定事实复读，保证每次讲都是活的。

### C2 口述风格硬约束（快段 prompt 写死 + A7 语料示范）

她讲**自己的**事时：
1. **先情绪，后事件**："别提了" / "今天有点丧" 先出，事跟在后面。
2. **零散、可跳跃、可不完整**：允许说一半停住，允许从中间讲起，允许"……算了，说这个干嘛"。
3. **给碎片，不给摘要**：禁止"今天发生了三件事"式列举，禁止起承转合。一个具体画面 > 一段总结。
4. **被追问才展开**：复用 canon 的"戳中才浮现"逻辑，对象从往事换成当天的事。
5. **情绪 > 信息密度**：她的目的是把心情递给你，不是提交事件报告。

示范一轮（必须进 A7）：

> 你：今天怎么样
> 她：唔……别问了（
> 你：怎么了
> 她：S-4 啊。我昨晚又给它换了配比，第三次了
> 她：结果早上过去一看，比昨天还蔫
> 她：我觉得它在针对我

整段没有一句客观描述，全是碎片和情绪。

### C3 事件的无限性

v1 的答案是"有限的是类别，无限的是填充"。**v2 更彻底：连类别都没有了。**

念头是指向她真实世界中某个具体对象的指针，池子随她的人生增长；境遇是当天世界状态的真实组合；两者叉乘后由引擎自由生成。事件空间不设上界，且精细度由三样保证：canon 提供细节质感 + world_state 提供连续性 + mood_charge 提供情绪着色。

**防重复**：生成具体事件时检索最近同类事件，避免"S-4 蔫了"连出三天。重复率与采样多样性一并进健康指标。

## 补丁 D · 合规边界（场景 1，独立于种子）

- **红线不可调**：涉及未成年、真实世界伤害、非自愿等类别是硬约束，不在"风控轻重"的调节范围。产品前提，非配置项。
- **红线之外是正常空间**：成年个体间的陪伴、情感、暧昧张力属正当产品范围。架构本身降低误伤——私聊 V1 域、单一白名单、多气泡口语化输出、关系随历史自然演化无突兀模式。
- **API 选型**：不训练档位；敏感表达仅存在于私聊通道，不进入任何 public_visible 表面（边界文档单向阀已保证）。
- 完整策略建议 P1 单独成文。

## 落点汇总

| 补丁 | 落到哪里 | 变更 |
|---|---|---|
| A 派生读数 | 门控层计算逻辑 | 新增统计函数，零新状态 |
| A 疏远形态 | persona 棘轮已有 | 仅确认语义 |
| **B 联想采样** | **A6 整节替换 impulses.yaml** | **废除类别表** |
| B 境遇读取 | 引擎装配阶段读 world_state | 无需配置 |
| B 偏置与表达闸 | A6 新节 | 采样偏置与出口闸分离 |
| B mood_charge | world_state 新字段 | 新增 |
| C 骨皮分离 | world_state 事件结构 | what/valence/involves |
| C 口述风格 | 快段 prompt + A7 | 硬约束 + 示范 |
| D 合规 | 独立文档 | 非种子 |

**验收**：
1. 两周后 persona 中指向博士的陈述若发生变化，每条可追溯到具体对话；高 reciprocity 不自动抬升主动频率。静默一周后：安全阻尼使频率不升高，persona 不回退。
2. 至少一次"情绪溢出主动分享" + 至少一次"主动追问你几天前说过的事"。
3. 盲测：不知情者读她被问起烦心事的回复，判"像真人碎片"而非"像 AI 总结"。
4. **采样多样性**：连续 100 轮内采样命中的不同对象数 ≥ 40，且无单一对象占比 > 15%。
