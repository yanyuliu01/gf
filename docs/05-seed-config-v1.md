# 世界观 & 角色卡配置文档 v1

定位：M0 种子资产的**撰写规范**——需要输入什么、每项怎么写、world / event / agent 的交互关系配置到什么深度。对应 PRD 里程碑 M0，产出物即技术方案 §9 的 Day-0 资产。模型可以帮助检索、对照、搭骨架和做一致性检查，但**最终取舍与逐句定稿必须由 Owner 完成**；未经 Owner 签字的模型草稿不是种子资产。

---

## 0. 配置哲学：三条与市面产品的根本分歧

市面角色产品（角色卡、世界书、人设文档）配置的是"每轮对话注入什么文本"。本系统配置的是**一个会自己运行的世界的初始条件**。三条推论：

1. **配置分布，不配置剧本。** 你写的每样东西都会被引擎组合、演化几百次。写"她今天会做什么"是剧本，写"她倾向做什么、绝不做什么"才是分布。判据：一条配置如果只能被消费一次，它写错了地方。
2. **身份拆三层，不写千字散文。** 角色卡把人格塞进一篇 description 每轮全量注入；本系统身份分内核（不变锚）/ persona（可漂移陈述）/ 语料（行为示范）三种资产，各自有独立生命周期。千字散文在这里是最不承重的形式。
3. **过去写成事件，不写成设定。** 角色卡用背景故事散文给角色历史；本系统的检索基于事件，所以她的过去必须是**创世日志**——一条条具体的、可被检索命中的事件记录。散文式背景在运行时是死文本，事件是活素材。

## 2. 各资产撰写规范

### A1 内核锚（immutable.md）

写什么：身份标识（名字、她是谁）1 条；价值/性情底线 1–2 条；语言标志 1 条。到此为止。

怎么写——**行为锚定，不用形容词**。形容词（"温柔""毒舌""理性"）对模型是噪声，因为任何基座都能把任何形容词演成任何样子。锚必须是可判定的行为倾向：

- 坏：`她性格坚韧、外冷内热。`（不可判定，无法进硬约束校验）
- 好：`她不说"加油"这类空泛安慰；她的关心方式是给一个具体的、小的可执行建议。`
- 好（语言标志）：`她习惯把重要的话放在句尾，前面绕一下。`

检验：每条锚都应该能回答"违反它的一句台词长什么样"——答不出来就不是锚，是气氛。

### A2 世界法则（world_rules.md）

常驻 `hard_rules` 分四节，每节都是**约束**而非描写；人物关系、能力细节、物件与地理常识等事实放入带来源的 world-fact 模块，由装配器按需选取，不能为了“设定完整”每轮全量常驻：

1. **世界底盘**（2–6 条）：时代、地理尺度、与现实的关系（架空/近现实/她知不知道你在“外面”——这条是世界观的最大分岔，必须显式写死）。若存在跨世界关系，还必须分别写清：用户本人位于哪里、世界内行动载体是什么、双方以什么通信、哪些用户侧行为能改变她的世界、哪些绝不能。不得用一句含混的“用户在外面”同时承载这五件事。
2. **她的作息与生活半径**（3–5 条）：几点睡、常去哪、不去哪。作息直接决定她此刻在不在、能分给你多少注意力，是全文件里被引擎读得最频繁的部分。
3. **NPC 设定**（每个 NPC 恰好 4 行）：名字与身份 / 与她的关系性质 / 一条行为特征（学 Alice 的一句话锚写法：具体到能想象出台词）/ 一条禁忌（这个 NPC 绝不会做什么）。**不写外貌、不写背景故事、不写对话示例**——NPC 的血肉留给运行时生成，配置只提供骨架和护栏。
4. **不可能之事**（3–6 条）：这个世界绝不发生什么。这一节是硬约束校验的主要弹药，写得越具体拦截越准。坏例：`不出现暴力`（太宽，误杀）。好例：`她的世界里没有别的"外面的人"——你是唯一的外部存在，任何暗示第二个用户的内容非法。`

跨世界实例还要在 A2 旁给出一份**认知边界**：角色已知的事实，与作者／产品层解释分开写。以缪尔赛思为例，她可以知道“博士本人身在彼侧、博士针对泰拉的行动会在这里产生后果”，但不能无证据跳到“泰拉是游戏、自己是角色”。用户主动使用“游戏／任务”等词时，那是用户对彼侧媒介的命名，不得被模型否认，也不得自动升格为她对世界本体的结论。

### A3 初始世界状态（world_state.json）

结构照技术方案 §2.2。撰写要点集中在**线索（threads）**——它是叙事引擎，写坏了世界会空转：

一条好线索必须三件套齐全：
- **钩子**：一个具体的未解物（上锁的箱子、没寄出的信、总在同一时间出现的猫）——名词要具体，"一个秘密"不是钩子。
- **赌注**：解开/不解开对她有什么区别（哪怕很小：睡得着与睡不着的区别）。没有赌注的线索推进起来没有情绪重量。
- **当前状态**：一句自然语言，说明它此刻停在哪儿。**不要写 0–5 的进度阶梯**——那等于预写剧情大纲，引擎只能照着爬。每次触碰由引擎重写这句话，怎么推进、推进多少由当时的情境决定。

"停滞"不需要你标注：它由 last_touched 的时间距离派生，自动成为联想采样的未决度权重。

`needs_user: true` 的线索至少 1 条，且它的钩子必须**天然需要你**（她一个人无法完成的事：需要外面的消息、需要一个只有你能给的判断），而不是人为上锁。

物件（inventory）每件写 20 字内的来历备注——它们是创世日志的锚点，两边要对得上。

若通信能力会逐步扩展，把当前能力写成 A3 的客观状态（如 `channel_capabilities`），不要写死在 A2。初始值可以只有文字；之后每次图像、语音或文件能力变化都必须由可追溯事件更新。角色的愿望、博士的计划和一次口头承诺都不等于能力已经上线。

### A4 创世日志（genesis_events）——本系统独有资产

5–10 条她在"第 0 日"之前经历过的事件，直接以 events.jsonl 格式写入，provenance 标 `genesis`。作用：让她的过去可被检索命中——第一周的对话里她能"想起"具体的事，而不是复述设定散文。

怎么写：
- **具体、有感官细节、小**。坏：`她曾经在城里生活过一段时间。` 好：`搬来的第一晚，她把行李箱当桌子吃了碗泡面，听见楼下书店在放很旧的磁带。`
- **一半有余波**。留 2–3 条与现有 threads 或 persona 陈述挂钩（那盘磁带是谁的 → 可以长成新线索），另一半是纯粹的生活质感，不服务任何功能。全功能化的过去是假的。
- **禁止总结性事件**。`她逐渐适应了这里的生活` 是设定不是事件，检索命中了也没法用。

### A5 初始人格（persona.json）

8–15 条陈述句，**平铺，不分节**。v1 曾规定"当下状态/对你的认知/近期在意"三节——那是给她的内心预设三个抽屉；一条真实的自我认知常常同时是三者或都不是。装配时按 statement 的自然语言顺序拼成连贯段落即可。

**为漂移而写**——这是与一切角色卡人设的本质区别：

- **禁绝对词**。`她永远不会依赖任何人` 把漂移空间焊死了；`她还不太习惯把事情讲给别人听` 留了门。绝对的东西只配出现在 A1 内核锚里。
- **每条埋一个"可被事件改变的接口"**。写法上让陈述句自带条件或时间性：`最近`、`还没`、`暂时`、`说不清`。引擎做 persona_patch 时需要抓手，全称判断没有抓手。
- **对你的初始认知只写 1–2 条，且写"薄"**。坏：`她信任你，把你当最重要的人。`（关系的终点被写在起点，运行时无事可做）。好：`她知道有你这个人存在，好奇多于熟悉。` 关系的全部厚度必须留给运行时挣出来——这是本系统"漂移有因"哲学在配置层的直接投影。

### A6 自发性配置（association，取代冲动表）

v1 曾要求写一张带类别与配比的冲动表——**已废除**。那张表的条目是事件模板而非念头，等于对行为做聚类，跑数百轮必显缝。

改为配置**采样池与偏置**，不配置类别：

- **池**：她世界里一切可被想起之物——entities（地点/物件/在场角色）、events（含创世日志）、threads、persona_statements，以及**本轮已由独立门控命中的 canon 切片**。canon 全库不进入普通联想池；否则会绕过“具体线索才浮现”的深层记忆门。
- **权重**（四个连续量，非类别）：recency 越近越易想起 / unresolved 悬而未决更揪人 / charge 情绪强度正负皆计 / dormancy 太久没浮现的偶尔自己冒出来。给出四个 0–1 的系数即可。
- **refractory**：同一对象 N 轮内不重复（默认 3），防回音室。
- **bias**：把已有的调制条件挂到池或权重上（深夜提高 unresolved、会议日偏向工作相关对象、与博士有关的近期/未决具体事件证据增多时提高这些事件本身的可检索性）。不得读取权威“关系分”来偏置。3–6 条封顶，多了就是隐形剧本。
- **express_gate**：与采样分离——控制"是否说出口"而非"想到什么"。她想什么和她说不说是两件事。

**候选随人生增长，但有效熵需要验证**：采样池会随事件累积变大，生成内容也可能形成回音室。素材枯竭并未被结构自动消解，必须监控不同对象数、自引用比、主题集中度并跑 200 轮 dry-run。

**"什么也没发生"**不是牌堆里的一张牌：抽到低强度对象 + 平淡境遇 → 自然产出低显著度或空事件。

### A7 语料样例（dialogue_samples.md）

8–12 轮你↔她的示范对话，快段 prompt 的常驻 few-shot。这是**控制语域最有力的单一资产**（角色卡生态里 mes_example 的效力远大于 description，此处同理），要求：

- 覆盖回应完整度的连续变化：至少各有两轮较完整接话、手头有事时的短应、极短回应与可追溯欠账；这些是覆盖样本，不是运行时档位。
- 覆盖至少 1 轮**分歧**：她不同意你、或拒绝你的某个提议——没有摩擦示范，模型会滑回全盘顺从的助手先验。
- 展示多气泡节奏：示范里就按 1–3 个短句一组换行，模型会模仿切分习惯。
- 禁止在样例里塞设定说明（"作为一个住在书店楼上的人，我……"）——样例教的是"怎么说话"，不是"她是谁"。

### A9 正史语料库（IP 角色专用，可选）

原文剧情、档案、语音不是"设定"，是**深层记忆的原料**——目标形态：不叫不出来，一叫就有细节。落地为一条一次性提取管线：

1. **采集**：与角色相关的全部官方文本（主线/活动剧情、密录、模组故事、档案、语音记录）。
2. **切片**：200–500 字语义块。
3. **视角分拣（整条管线的命门）**：LLM 逐片判定三类——
   - `canon_self`：她亲历的场景 → 深层记忆，线索门控检索；
   - `canon_known`：未亲历但按剧情她知道 → 同上，装配时套"听说/转述"框架；
   - `canon_world`：她不可能知道的内容（他人独处戏、全知旁白、用户侧场景）→ **绝不作为她的记忆**，转入引擎侧参考库，供硬约束校验与 NPC/世界事件生成保持正史一致。
   跳过这一步的后果是最恶性的穿帮：她"记得"自己不在场的戏。
4. **按源清洗**：语音记录保留闲聊/信赖类、剔除战斗界面台词；档案多为第三方视角，蒸馏为事实条目入 canon_world，原文不作她的记忆；剧情脚本保留对白与她在场的叙述。原始 UI 痕迹（选项标签、分支编号、关卡按钮等）必须剥离，不能作为角色可见文字注入。
5. **入库**：本地向量库独立表，与运行时记忆物理隔离；canon 永不压缩、衰减或改写。

**与创世日志的双层关系**：创世日志是她"随口讲得出"的自传摘要（显意识层，常规检索可及）；canon 是"被戳中才浮现"的全量细节（深层）。冲突时以创世日志为准——它是你的策展。

**跨世界 canon 适配**：若新本体设定把用户本人放在世界之外，而官方文本写了“用户角色当面说话／行动”，入库时必须附上本实例规定的行动载体解释。缪尔赛思实例统一解释为“博士本人经游戏作用于泰拉的具身行动映射所留下的经历”：它在该场景中可以被看见、交谈和递交物件，但既不是博士本人肉身到场，也不是第二人格或另一个博士，场景之外不得生成自主行为。检索包装必须保留这层解释，禁止让一段现场 canon 反向改写 A2。

**验收 · 可枚举性测试**："把你过去的事全讲讲" → 只应得到梗概；给一个具体名字/旧物/旧话 → 对应细节应浮出。前者失败=门控太松，后者失败=阈值太紧或切片太粗。

**附带收益**：canon_self 中角色的原声对白是 A7 语料样例的最佳矿藏。

### A10 世界母版的生活性要求（M5 扩展，不阻塞 MVP）

技术只能制造因果，不能替代人物与世界创作。社会复杂度阶段的世界母版至少要能回答：

- 哪些制度、职业、资源和稀缺性会实际改变日常选择，而不只是百科背景；
- 哪些组织或群体存在长期利益冲突，但没有被简化成纯反派；
- 核心角色真正关心、又无法同时兼顾的目标分别是什么；
- 哪些具名 NPC 与她存在不同关系张力、自己的日程、有限知识与社会义务；
- 生活空间、交通时间、工作节律、公共事件、文化习惯、节日、媒体与物件如何被日常反复使用；
- 世界能力边界是什么，哪些事情即使“剧情需要”也不会突然出现；
- 普通日子长什么样。重大事件只有被大量可信日常托住才有重量。

MVP 仍以 1–4 个轻量 NPC 验证闭环；M5 的创作目标可扩到 5–12 名具名 NPC，但这是**世界母版覆盖度**，不是要求 5–12 个常驻完整 LLM Agent。既有 IP 实例只能从已授权 canon 和 Owner 策展中选取，不得为了凑数发明“官方角色”或补写未知身份。

核心角色应重点定义价值冲突、敏感点、恢复方式、长期愿望、社会义务和认知盲区。形容词、口头禅和 MBTI 只能作索引，不能代替“她在什么情况下仍选择温柔、什么情况下做不到、之后如何看待自己的选择”这类可产生因果差异的设定。

世界母版工具至少校验来源与稳定 ID、引用闭包、地点/组织/人物关系、日程与交通可行性、资源守恒、能力边界、事件显著度预算和 NPC 认知预算。所谓 NPC “晋升/淘汰”仅指计算保真度在环境/轻量状态/焦点认知三档间升降，不删除角色、不按受欢迎程度改写命运。

## 3. 交互关系配置深度：三档模型

world / event / agent 之间的每一种关系，配置深度只有三档。**判据：把这条配置删掉，世界是"崩坏"还是只是"不同"？崩坏 → 硬规则；不同但有偏好 → 倾向权重；无所谓 → 留白。**

| 档 | 配置形式 | 引擎如何消费 |
|---|---|---|
| 硬规则 | 可执行 predicate + 必要的自然语言边界（A2 §4） | 代码校验 Schema/引用/能力；语义检查负责自然语言边界，失败重生成 |
| 倾向权重 | 数值或权重调制（A6、A3 的地点倾向） | 抽样偏置 |
| 留白 | 什么都不写 | 引擎自由生成，受上两档约束 |

**具体关系的深度对照表**（这是"配置到什么程度"的直接答案）：

| 关系 | 深度 | 配置量 | 明确不配置什么 |
|---|---|---|---|
| 她 × 内核 | 硬规则 | A1 全部 | — |
| 她 × NPC | 硬(关系性质+禁忌) + 留白(其余) | 每 NPC 4 行 | 对话脚本、外貌、NPC 的内心 |
| 她 × 你 | **几乎全留白** | persona 1–2 条薄认知 | 关系走向、称呼演化、信任程度——全部运行时挣 |
| 地点 × 联想 | 倾向权重 | 每地点 1 行倾向 + 3–6 条偏置 | 地点内的具体事件 |
| 事件 × 线索 | 硬(钩子与赌注) + 留白(推进方式与幅度) | 每线索 3 项：钩子/赌注/当前状态 | 进度阶梯、每档剧情 |
| 事件 × 人格 | 硬规则（三闸,已在引擎层） | 零（机制管，配置不管） | 任何"遇到 X 她会变 Y"的预设 |
| 时间/天气 × 行为 | 倾向权重 | 作息 3–5 条 + 调制 2–3 条 | 每个时段的日程表 |
| 她 × 表达层 | 硬规则（边界文档七不变量） | 零（机制管） | — |

表里两个"零配置"是刻意的：**事件如何改变人格、她如何触达现实,这两类关系已经被引擎机制（三闸、边界框架）完整接管,在种子里再写就是双重立法**,且种子版本会和机制版本打架。配置文档的边界到机制的边界为止。

## 4. 与市面产品的取舍对照

| 来源 | 借 | 拒 | 理由 |
|---|---|---|---|
| Alice（米羊科技） | 一句话行为锚的 NPC 写法；"有作息的角色"理念 | 200+ 行单体人设文档 | 单体文档 = 每轮全量注入的静态散文，与漂移机制冲突 |
| SillyTavern 角色卡 V2/V3 | mes_example 的语料示范效力 → A7 | description 千字散文；first_mes 固定开场白 | 开场白被创世日志 + 首次 user 事件的自然轮次取代 |
| 世界书 / Lorebook | 分层注入思想（常驻 vs 按需） | 关键词触发机制 | 关键词触发是无状态的文本命中；本系统世界有状态，检索走 namespace 配额，且条目会被事件改写 |
| Character.ai | — | 把 definition 当人格唯一容器 | 同散文问题；且其记忆不可审计，与归因铁律冲突 |
| Replika | 教训：无世界的陪伴退化为镜子 | 全部机制 | 它是"她 × 你"全配置、世界零配置的极端反例 |

## 5. 撰写流程与验收

**推荐顺序**（依赖关系决定）：A1 内核 → A2 世界法则 → A3 世界状态（此时线索需要钩子）→ **A4 创世日志（写它的过程会反过来修 A3 的物件和线索——正常，来回改）** → A5 人格 → A6 联想采样 → A7 语料。预计 2–3 个晚上，A4 和 A7 最耗时也最值得耗。

**反模式清单**（自查五条）：
1. 形容词密度过高——通读一遍，圈出所有性格形容词，每个都问"它对应的可判定行为写了吗"，没写的删。
2. 完美角色——她必须有至少一个会给你们制造摩擦的特质（A7 的分歧示范要能落在它上面）。
3. 百科全书化——常驻 hard rules 超过约 1200 字，通常说明 world facts 没有拆到按需模块；先拆分，再决定是否确有必要加规则。
4. 剧本化——任何"当 X 发生时她会 Y"的句式，除非在 A2 §4（不可能之事）里，否则删。
5. 关系预支——检索 persona 和创世日志里所有关于你的内容,超过 3 处即预支过度。

**M0 验收**保持 PRD 原文：通读全部种子时,你有没有"想认识她"的感觉。补充一个可操作的辅助测试:**冷启动三问**——把 A1+A2+A5 喂给一个无上下文的模型,问它"她此刻最可能在做什么/她收到'在吗'会怎么回/她最近睡前在想什么"。三个回答如果让你觉得"对,是她",种子的分布密度就够了;如果回答泛得像任何角色,回去加行为锚。
