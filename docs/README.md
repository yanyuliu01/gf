单用户、世界为核心的自主陪伴 agent。她在你不在时持续存在，说的每句话背后有真实发生过的事，因你而改变且改变可追溯。

## 八个核心决策

1. **世界为核心，不是对话为核心**。你的消息是她世界里的一个事件，享有优先出队但**不抢占**。她可能在忙。买到在场感，代价是即时可用性。
2. **一切出向经唯一阀门**。膜上三个入向端口、一个出向管线，无旁路。observed 内容永不流向第三方可见的表面。
3. **漂移必须有因**。任何人格变更强制挂 event_id，无因拒写；限速；重大改变棘轮不可逆。
4. **关系由证据历史构成**。不设亲密度或多维关系真值——共同事件、相互披露、有限信念、承诺、冲突与修复共同构成关系；观测读数可重算且不得反向驱动角色。
5. **不优化留存**。指标永不反馈成“让你聊更多”的策略；reciprocity 只在低值区间作安全阻尼，达到中性值后不再提供额外增频（代码断言）。
6. **半透明第四面墙，单一关系链路**。博士本人始终在另一个世界；当前 IM 是双方唯一持续、直接的通信。游戏中的博士是他作用于泰拉的具身行动映射：可在有来源的任务／正史场景中被看见和交互，但没有独立意识，不等于本人肉身到场，也不自动推出“玩家／角色／虚构”解释。
7. **事实、信念、承诺分离**。事件账本持有事实权；角色和 NPC 可以知道得不全或判断错误；承诺是有来源、有状态、有代价的实体，`debt` 只是通信欠账特例。
8. **Affect Utility 不选择动作，也没有模态分身**。Utility 只让事件影响连续情绪、记忆显著性与注意；LLM 根据 Working Self 直接生成开放行动，不从有限语义候选中挑选。World Adjudicator 裁决实际后果；文本、语音和图像从同一 intent/state/source closure 渲染，不新增事实。

## 设计原则的演进史（八次废除）

本项目反复犯同一个病：**给本该从历史里长出来的东西预先建分类或刻度**。已废除或拦下八次，按时间：

| # | 废除了什么 | 换成了什么 | 病灶 |
|---|---|---|---|
| 1 | 抢占式对话回路 | 统一世界管线 + 无抢占 | 把她当服务而非存在 |
| 2 | intimacy 亲密度变量 | 共同事件、披露、信念、承诺、冲突与修复 | 给关系装仪表盘 |
| 3 | 冲动类别表 | 从她的世界联想采样具体对象 | 事件模板伪装成念头，对行为聚类 |
| 4 | 线索 status 枚举 + progress 0–5 阶梯 | 自然语言 current_state + 布尔 open | 预写剧情大纲 |
| 5 | 主动发言每日配额 + manner 三档 | 状态派生的开口阻力 + 有状态通信 debt 实体 | 把连续量钉成刻度 |

| 6 | （2026-08-05 拦下，未发生）人物描写写成"遇到 X 她会 Y"的场景反馈模式 | "她同时想要 A 和 B，而 A 与 B 不能兼得"的张力写法 | 分拣器伪装成"行为具体化" |
| 7 | （2026-08-05 拦下，未发生）关系多维向量 + 全局 Utility 总分 | 历史/信念/承诺为本体 + 合法候选的局部仲裁 | 把关系和人格重新压成可调仪表盘 |
| 8 | （2026-08-06 修正）有限语义候选 + Utility 选择 | 记忆驱动 Working Self + Affect Utility + LLM 开放行动生成 | 动态候选仍会收敛成行为树，情绪系统越权替主体做决定 |

**审计判据（下次还会犯，请照此打回）**：
- 这个枚举描述的是**客观事实**（来源、去向、真假、可见性）还是**主观/涌现现象**（心情、亲疏、进度、投入度）？后者一律拆。
- 它是在**描述她**，还是在**替她做决定**？后者一律拆。第 5 次就是伪装成"体验保护"才躲过了第一轮审计。
- **一条常驻的人物描写，如果能被写成"遇到 X 她会 Y"，它就写错了。** 前者是分拣器（输入情境查表输出反应，两百轮必露缝），后者是发动机（一组同时成立的相反欲望，每次在当下情境里现场演算）。第 6 次是从外部产品借鉴时混进来的——**借工程手法可以，借人设形态要过这道判据**。
