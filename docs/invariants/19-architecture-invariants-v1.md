# 架构不变量 v1（冻结）

- 状态：**已冻结**
- 冻结日期：2026-08-07
- 性质：**约束层权威**。本文持有跨阶段不可协商的架构约束
- 不持有：任何字段、schema、参数、阈值或数据形状

---

## 0. 这份文件是什么

本项目已经历八次「废除预建分类或刻度」。每一次废除都在事后被记录，但**约束本身从未有过正式住处**——它们散在 `docs/02`、`docs/04`、`docs/10`、`docs/13`、`docs/18` 和 `AGENTS.md` 里。其中 `AGENTS.md` 承载了最完整的一份清单，而 `docs/README` 第 9 条明确规定根目录的 handoff / TODO / AGENTS「只负责交接、进度与工程纪律」，即非权威。

后果是：**最该被守住的东西，住在一份声明为不算数的文件里**，下一轮演进可以合法地绕过它。`docs/history/12-v2` 的五条发现因未入库而在分支演进中整体丢失，是同一类失效的实例。

本文把约束层固定下来。它的判定范围是「这个改动是否被允许」，不是「这个字段该怎么写」。

## 1. 冻结的范围

**冻结**：本文第 3 节的全部条目。它们描述权责、可见性边界与禁止形态。

**不冻结**：

- 任何 JSON Schema 的字段集合
- 任何数据库表结构
- 任何模块的内部字段清单（含 Working Self 的组成、Affect 的状态维度、精力账户的结构）
- 任何参数、权重、阈值、时间常数
- 资源表、生产配方与世界初始禀赋
- 检索维度的具体定义
- `docs/17` / `docs/18` 的认知精力经济（见 §4）

理由：M0 Contract Freeze 冻结了 12 份 schema 与 411 行 DDL，全部通过静态校验，随后在 M1 实现中暴露出全库来源闭包、UTC 时区、canon 未接线、种子未加载等问题。**契约冻结检查的是内部一致性，不是与现实的一致性。** 数据形状的正确性取决于运行中发现什么，因此不进入本次冻结。

## 2. 修改程序

本文条目的推翻需要：

1. 一份 ADR，写明推翻的是哪一条、依据什么运行证据、代价是什么；
2. 对应主题权威文档的同步修改；
3. 原条目保留并标注为已废除，附推翻日期与 ADR 引用。**不删除历史条目。**

新增条目同样走 ADR。未经此程序的约束变更无效，即使它出现在实现、Prompt、任务板或交接文档中。

## 3. 不变量

### A · 事实与写入权

- **A1** 世界事实只存在于已提交的 `WorldEvent` 与 reducer state。
- **A2** StateManager 是唯一权威状态写者。模型、adapter、Memory、Affect、World Adjudicator 一律只能提议或派生。
- **A3** 行动提案不得自己宣告成功。实际后果由 World Adjudicator 裁决，其输出同样是 proposal，仍须经校验后提交。
- **A4** 删除任何派生表或切换任何可拆卸模式，不得损坏事件账本、reducer state、消息、承诺来源、speech 或 outbox。

### B · 事实、信念与承诺

- **B1** 事实、主体信念与承诺三者分离。角色可以知道得不全或判断错误；误解本身是关于她的事实。
- **B2** 承诺与关系**不建立权威容器**。承诺的事实是账本中的原话；任何 commitment 记录都是从账本派生的投影。
- **B3** 派生投影对 World Adjudicator 与审计侧可见，对 Working Self 与 Open Policy **不可见**。冲突时以账本原文为准。
- **B4** 派生读数（reciprocity、通信欠账、关系读数）可随时重算，且**不反向驱动角色**。
- **B5** 两个主体对同一次交互可以持有不一致的理解。这是特性，不是需要消解的数据不一致。

### C · 感知与认知

- **C1** 她读到的是 Perception 投影，不是世界状态本身。世界中存在但未被她观察到的事实，不进入她的上下文，也不进入来源闭包。
- **C2** Working Self 是一次调用的只读派生视图，按当下情境组装。它不是固定槽位的并列填充。
- **C3** 认知能力受连续资源约束。约束在引擎侧生效；容量包络与任何数值账户、token 计数、价格、供应商字段**永不序列化进入角色上下文或表面**。
- **C4** 容量不足时优先削减可选广度。当前已鉴权消息、安全事实、已接受承诺与关键反证不可被削减。无法满足时 fail closed——排队、等待恢复或暴露非叙事的系统状态，**不得伪造角色状态作为借口**。
- **C5** 检索必须能同时召回支持与反对当前判断的证据。情绪或当前假设不得压制相关反证。

### D · 情绪

- **D1** Affect 不给动作排序、不选择动作、不直接发送消息。
- **D2** Affect 的作用范围是检索显著性与注意力分配。
- **D3** 情绪通过**她亲历的来源事件**进入上下文，不通过状态标签、等级或预制语义区间进入。
- **D4** 底层是隐藏账户的（token、精力），只约束不呈现；底层是她亲历的（事件），呈现证据由她自己解释。
- **D5** 主体对自身状态的解释是有来源约束的开放文本。它可以缺省、可以迟滞、可以误判、可以与客观账户不一致；它不修改任何账户、不修改世界事实、不决定行动。
- **D6** 不存在 `energy > x → tired` 一类映射，不存在按状态区间预写的应对动作。

### E · 行动

- **E1** LLM 生成开放语义行动。**不得**从有限语义候选集中挑选，也不得临时生成候选集再排序——动态候选在长期运行中会收敛为行为树。
- **E2** 底层执行器可以拥有有限能力接口（如 communicate / observe / move / use_object / wait）。它是系统调用层，不反向限定主体可以想出什么。
- **E3** 一切出向内容经同一 surface / outbox / adapter 路径，无旁路。
- **E4** 不存在全局可累加、可持久化、可调参的行动总分。

### F · 可拆卸

- **F1** 目标管线必须能在 `off` / `shadow` / `active` 三态下运行，`off` 必须可独立运行。
- **F2** `shadow` 与 `off` 的 Wake 决策、精力结算与 Policy 输入必须完全一致，差异只允许出现在审计产物中。
- **F3** 可拆卸模块只能作为主链的**旁路输入**，不得成为主链上的环节。判据：拆掉它之后主链是否仍然连通。
- **F4** 每个可拆卸模块必须有删除标准——在同模型、同事件、同预算的纵向测试中无法证明增益时如何处置。没有删除标准的模块不得声称自己可拆卸。

### G · 倾向与学习

- **G1** 倾向改变通过检索实现，不通过蒸馏出的规则实现。不设跨场景蒸馏器。
- **G2** 新增的 persona 陈述如果能写成条件句（「遇到 X 她会 Y」），即为退化，应当拒绝。**自动生成不豁免此判据。**
- **G3** persona 是慢通道，受归因、限速、棘轮三闸约束；只有重大到值得棘轮的变化才落地。
- **G4** 接受「相关经验未被召回时她不会改变行为」这一失败模式，优先于制造一个必然记得的机器。

### H · 伦理

- **H1** 不为留存、响应率、付费或情绪压力优化角色行为。任何指标不得反馈进角色策略。
- **H2** 负面情绪、用户久未联系与低 reciprocity 不得提高主动触达倾向。阻尼在低区间单调、在中性值以上导数为零。
- **H3** 运营成本熔断只产生系统状态，不得生成主观疲劳、疲劳记忆或任何借角色之口的成本解释。
- **H4** `/mute` 冻结全部出向端口。

### I · 跨世界与边界

- **I1** 跨世界事实依 `docs/10`。博士彼侧的普通生活不自动改变泰拉；只有明确报告或经验证的可信系统事件才能形成泰拉事实。
- **I2** 世界模型的边界即 `docs/04` 的膜。膜外的对象不进入资源流，只经三个入向端口进入。
- **I3** 具身行动映射不是第二主体，不注册为独立实体，不拥有独立人格、记忆或场景外自主行为。

## 4. 明确不在本次冻结内

**认知精力经济**（`docs/17` 账本机制 + `docs/18` 涌现式主观体验）保持「现役设计」状态，不进入冻结。

它与其余各层的性质不同：其余各层描述的是已存在的东西该怎么组织，它是为了产生一个当前不存在的现象而新引入的机制。且它目前是唯一一个**没有删除标准、而 `off` 基线又拆不掉**的模块——这与 F4 存在张力。

约束层中与它相关的条目（C3、C4、D4、D6、H3）已经冻结，因为那些是**边界**而非**机制**：无论精力经济最终采用什么结构，数值不进上下文、不可削减必要内容、成本不伪装成疲劳都成立。

若要将其纳入冻结，前置条件是补一条与 `docs/13 §10.3` 对等的删除标准。
