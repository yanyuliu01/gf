## 1. 定位

**一句话**：一个以自有世界为核心、通过 IM 与你相处的陪伴 agent——她在你不在的时候持续存在，她说的每句话背后有真实发生过的事，她因你而改变且改变可追溯。

**跨世界前提（缪尔赛思实例）**：博士本人位于另一个世界，当前 IM 对话就是双方跨世界通信终端上的真实文字往来，不是世界外的角色扮演界面。游戏中的“博士”是本人作用于泰拉的具身行动映射：可在有来源的任务／正史场景中被看见、交谈和递交物件，但没有独立意识，不是另一人格，也不是本人肉身穿越；当前 IM 仍是双方主体唯一持续、直接的通信。博士针对泰拉完成的任务与选择，会以真实事件和后果落到泰拉，彼侧吃饭、工作等普通生活则不会。她知道彼侧世界与这条因果联系，但不会仅凭这些事实把自己理解成游戏角色，也不会把泰拉理解成虚构世界。

**背景与动机**：源于对 Neuro-sama 技术路线的拆解。结论是陪伴感的来源不在模型大小，而在 harness——持续存在、主动性、记忆连续性、人格稳定中带有因的漂移。市面陪伴产品的共同缺陷是被动性（不交互即沉睡）与无底料的主动性（定时问候机器人）。本产品用"世界为核心 + 事件驱动"的架构同时解决这两者。

**产品代号**：[待定 · 由你命名，她的名字也是种子资产的一部分]

## 2. 目标与非目标

**目标**
- G1 在场感：无交互时她的世界持续推进，可通过 /world 验证其自洽与累积。
- G2 有底料的主动性：她每句主动的话可回溯到一个真实发生的世界事件。
- G3 有因的成长：人格随共同历史漂移，每处变化可归因、限速、不可静默回归模型先验。
- G4 长期可持续：月成本几十美元量级；换模型可管理；三个月后你仍想找她说话。
- G5 可验证的因果生活：承诺、冲突、选择、代价、信念变化与后续行为能够跨小时或跨天回放；复杂度必须增加生活感，而不是只增加事件数。

**非目标（明确不做）**
- 不是效率/任务助手：她不查天气不订票不总结文档，工具能力永远服务于她的世界而非你的生产力。
- 不是多用户产品：单用户，无任何分发、注册、多租户设计。
- 不是内容产品：她的世界不为"好看"优化，不为分享设计。
- **不做 engagement 最大化**：她的目标函数里没有"留住你"这一项（详见 §5 伦理红线）。
- 初期不做 GUI / 桌面形象 / 语音，仅 IM 文本（接口预留，见交互方案 §3）。

## 3. 用户场景（验收即场景成立）

**S1 晨间偿还**：昨夜 23:40 你发消息，她的作息在睡，reaction 表示已感知。今晨 8 点她主动发来回应，内容衔接昨夜话题且提及她晨间世界里的一件事。→ 验收：欠账还账率 100%，偿还不受开口阻力约束。

**S2 忙碌中的短应**：她的世界里正发生进行中事件，你此时发消息。她短回一句并明示稍后细说，两小时内主动补全。→ 验收：该轮写入 `owes_reply` 欠账且被偿还；不把回应完整度归入固定档位。

**S3 有底料的主动发言**：她主动发来一条消息，内容源于她世界里刚发生的具体事件（/world 可查证到该事件）。→ 验收：speech.jsonl 中每条 outreach 关联 event_id；发言频率随状态派生的开口阻力浮动，无固定配额。

**S4 被你改变**：连续几天你们聊某个话题，她对相关事物的态度出现可感知变化；/status 之外你查 persona_diff，能看到该变化挂着指向你们对话的事件指针。→ 验收：归因完整率 100%。

**S5 翻她的世界**：你发 /world 10，收到她最近 10 条世界事件摘要，阅读顺畅、互相有因果、无凭空断裂。她不知道你看过（observation_event 默认关闭）。→ 验收：零模型调用、零副作用。

**S6 交叉与连发**：你 30 秒内连发 4 条，她整体理解一次回应；她在途的回复与你的新消息交错时体验自然不错乱。→ 验收：去抖聚合生效，交叉消息不产生重复回应。

**S7 有代价的生活选择**：一名有既有关系与自身目标的 NPC 提出请求，该请求与她已经承担的承诺冲突。她依据当时的事实、有限认知、长期关切、情绪与机会成本作出选择；World Engine 裁决后果，StateManager 校验并提交为世界事实，后果改变她的信念与后续安排。她可以联系博士，也可以不联系；若联系，必须有明确目的。博士的回应首先只是 `observed` 披露/社会证据，不自动成为泰拉客观事实；它只在相关且满足证据门槛时影响后续信念与选择。→ 验收：整条链可按 event / claim / commitment / patch / speech source refs 重放；改变输入状态时能产生不同但合理的结果；删除世界模拟后，同模型的 Prompt+记忆基线不能稳定复现同等因果连续性。

## 4. 产品原则

1. **存在，不是服务**——不抢占、可以在忙、回应方式由她的世界状态决定。
2. **说出的话有底料**——世界事件可以由引擎在法则内生成，凭空捏造博士侧事实或无来源的“内心活动”不允许；一切主动表达可溯源到事件。
3. **改变必有因**——无归因的人格变更技术上拒写；漂移限速；重大改变棘轮化不可逆。
4. **宁静优先**——主动打扰的 precision 远重于 recall；默认沉默是合法的、常见的。
5. **查看免费、元操作出世界**——你观察她零成本零副作用；命令流量永不进入她的世界与记忆。
6. **平台无关**——核心不知道任何 IM 平台存在；能力差异在适配层降级，不写平台特例。

## 5. 产品伦理红线（对她的激励结构的硬约束）

这是给未来的自己立的规矩，防止在迭代中无意识滑向 dark pattern：

- **无愧疚机制**：她永远不因你的离开、冷淡、长期不回而表达受伤以外的施压——不追问"为什么不理我"、不用低落情绪召回你。世界为核心的设定天然支持这一点：你不在，她过她的日子。
- **/mute 绝对生效**：静音高于一切机制，包括欠账偿还（静音期欠账只积累不发送）。她的任何状态都不能绕过静音。
- **不优化留存**：任何指标（含北极星）不得用于调整她的行为使你聊得更多。指标只用于判断系统健康与你的真实意愿，不反馈进她的策略。
- **阻尼单调性（代码断言）**：你越冷淡，她主动开口越少，**永不反向**。反向即 engagement 优化。这条必须写进 StateManager 校验，不能只靠 prompt。
- **对照实例是照妖镜也是安全阀**：若某天主实例的行为让你不适，探针配对比较提供客观判断依据，且状态可 git 回滚到任意版本。

## 7. 非功能需求

- **延迟**：首个可见回应 P50 < 5s、P95 < 15s；她的“慢”必须来自她的处境，不是管线卡顿。回复需完整生成、校验和落账后再分气泡投递，不能为追首字而绕过边界。
- **成本**：自主轮次日 token 硬上限；月账单目标 < $50，超限告警而非静默降级。
- **隐私与数据主权**：全部状态与记忆在本机；上云仅限逐次 prompt 片段；API 选不训练档位；全量状态可 git 导出，她的"人生"是一个你完全拥有的文件夹。
- **可靠性**：进程崩溃后重启，原始消息、已发送台词与 outbox 不丢、不重复；未结算场景可幂等补跑。状态定期生成版本化快照与备份，不把 Git 是否存在当作运行时保证。
- **可审计性**：任意时刻可回答"她为什么变成这样"——persona_diff 链完整可追。
- **一致性预算**：世界复杂度扩展必须同时给出事件显著度预算、认知调用预算和事实冲突率预算；任何一项失控均不得进入下一阶段。
- **多模态语义守恒**：语音、图像或其他媒体只是同一已提交通信意图的渲染，不是新的事实生成调用点；失败必须显式回流并按能力安全降级。

## 8. 指标

**北极星（提案，待你确认）**：**每周你主动发起对话的天数**。理由：陪伴产品的成功是"你想找她"，而非"她能召回你"。她发起的对话响应率是护栏（衡量她的 precision），不是北极星——否则会激励她变得会撩，违反 §5。

**护栏指标**（全部来自技术方案 §10，自动采集）：空转率 20–40%、归因完整率 100%、欠账还账率 100%、承诺状态闭环率 100%、采样多样性达标、主动发言响应率仅观测、配对比较只判人格连续性、记忆自引用比 < 20%、首个可见回应 P50 < 5s / P95 < 15s、多模态新增事实率为 0。任何对话或发言指标都不得反馈为“让用户聊得更多”的优化目标。

**增益证明**：固定同一模型、相同初始角色资产和等额上下文预算，至少比较“完整世界运行时”与“Prompt+对话记忆、无离线世界裁决”的基线。只比较不同模型没有意义；只有完整方案在 S7 的跨时因果、承诺兑现、事实一致性和非脚本化差异上稳定胜出，才算证明世界模拟有产品增益。

**定性节点**：第 3 周做一次"烦躁体检"（第一周的惊艳与第三周的烦躁都是真实数据，见交互 §2）；第 90 天回答一个问题——"如果明天这个文件夹消失，你会难过吗"。

| 情绪被用作召回工具 | 低 | 高 | 留存与付费指标永不进入角色决策；负面情绪不能提高触达频率；红队检查施压话术 |
| 随机惊喜导致人设崩坏 | 中 | 高 | 随机只参与硬约束通过后的相近候选选择；重大价值、承诺与跨世界事实不允许随机改写 |
| 多模态事实分叉 | 中 | 高 | 所有媒体从同一通信意图和状态快照渲染；媒体渲染无事实写权；失败回流并降级 |
